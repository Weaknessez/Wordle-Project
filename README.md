# Terminal Wordle in C++

A fully functional clone of the popular game **Wordle**, currently built to run inside a command-line interface but can and will be made into a web interface/program later on. This project was developed as a learning experience to understand C++ and core **Object-Oriented Programming** concepts. Later on will practice front-end UI.

Next push will likely add fixes if needed aswell as a new front-end rather than terminal.
